# NFL Playoff Bracket 2025-26

Interactive NFL playoff bracket showing the 2025-26 postseason, including Wild Card, Divisional, and Conference Championship rounds.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## Features

- **Full bracket**: every playoff game with its result
- **Conference filter**: show AFC, NFC, or both
- **Overtime indicators**: games decided in overtime are marked
- **Championship focus**: current championship games are highlighted
- **Responsive, dark UI**: works on phone and desktop

Game results are stored in `app/page.tsx`; update them there as the postseason progresses.

## Built With

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
