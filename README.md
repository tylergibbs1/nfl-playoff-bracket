# NFL Playoff Bracket 2025-26

Interactive NFL playoff bracket showing the 2025-26 postseason, including Wild Card, Divisional, and Conference Championship rounds.

## Features

- Real-time playoff bracket with all game results
- Interactive conference filter (AFC/NFC/Both)
- Responsive design
- Dark mode UI
- Overtime indicators
- Current championship games highlighted

## Built With

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## Deploy on Vercel

The easiest way to deploy this app is to use the [Vercel Platform](https://vercel.com).
